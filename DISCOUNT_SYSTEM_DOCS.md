# Discount Code System Documentation

## Overview

This comprehensive discount code system provides a robust, scalable solution for managing promotional codes in the online bookstore. The system supports percentage and fixed amount discounts, category-specific promotions, user restrictions, and advanced analytics.

## Features

### Core Features
- ✅ **Auto-generated unique codes** with customizable prefixes
- ✅ **Advanced filtering** by book, category, minimum order value
- ✅ **Robust validation** with min order, max uses, per-user limits
- ✅ **Admin UI** for full CRUD operations with bulk actions
- ✅ **Cart/Checkout integration** with real-time validation
- ✅ **User feedback** with toast notifications
- ✅ **Analytics and reporting** with comprehensive dashboards
- ✅ **Security** with permission-based access
- ✅ **Error handling** with retry logic and circuit breakers
- ✅ **Caching** for improved performance

## Database Schema

### DiscountCode Model

```javascript
{
  code: String,                        // Unique discount code
  description: String,                 // Human-readable description
  discountType: String,                // 'percentage' | 'fixed'
  discountValue: Number,               // Discount amount or percentage
  isActive: Boolean,                   // Active status
  startDate: Date,                     // Valid from date
  endDate: Date,                       // Valid until date
  maxUses: Number,                     // Maximum total uses
  usageCount: Number,                  // Current usage count
  maxUsesPerUser: Number,              // Per-user limit
  minOrderValue: Number,               // Minimum order requirement
  maxDiscountAmount: Number,           // Cap for percentage discounts
  applicableBooks: [ObjectId],         // Specific book restrictions
  categories: [String],                // Category restrictions
  autoGenerated: Boolean,              // Auto-generated flag
  prefix: String,                      // Code prefix for auto-generation
  usedBy: [ObjectId],                  // Users who used this code
  createdBy: ObjectId,                 // Admin who created
  lastModifiedBy: ObjectId,            // Last modifier
  createdAt: Date,                     // Creation timestamp
  updatedAt: Date                      // Last update timestamp
}
```

### Virtual Fields

```javascript
{
  status: String,                      // 'active' | 'expired' | 'used_up' | 'inactive'
  usagePercentage: Number,             // Usage percentage (0-100)
  remainingUses: Number,               // Remaining usage count
  isExpired: Boolean,                  // Expiration status
  isUsedUp: Boolean,                   // Usage limit reached status
  effectiveStatus: String              // Combined status for display
}
```

#### Using Cart Context
```jsx

  const { 
    applyCoupon, 
    removeCoupon, 
    validateCoupon,
    hasActiveCoupon,

    cart 
  } = useCart();

  const handleApplyDiscount = async (code) => {
    const result = await applyCoupon(code);

    }
  };
```

### Backend Integration

#### Validating Discount Codes
```javascript
const result = await discountCodeController.validateDiscountCode(req, res);
// Returns: { valid: boolean, discount?: object, message?: string }
```

#### Creating Discount Codes
```javascript
const discountData = {
  code: 'SUMMER2024',
  description: 'Summer Sale 2024',
  discountType: 'percentage',
  discountValue: 20,
  maxUses: 1000,
  minOrderValue: 100000,
  categories: ['fiction', 'non-fiction'],
  startDate: new Date(),
  endDate: new Date('2024-08-31')
};

const result = await discountCodeController.createDiscountCode(discountData);
```
